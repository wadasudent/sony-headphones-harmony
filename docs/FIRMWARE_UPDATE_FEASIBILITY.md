# WH-1000XM6 固件升级接入评估

本次评估基于 2026-11-07 的应用版本 0.4.0。

## 结论

当前没有足够依据实现并交付可验证的 XM6 耳机端固件升级。继续保留固件版本读取；不增加具有刷写行为的按钮，不把打开官网或查看版本标为“升级完成”。没有向耳机发送任何固件升级命令。

## 已核对资料

- [索尼中国 WH-1000XM6 3.1.5 升级说明](https://service.sony.com.cn/download/firm/00003184.html)：官方流程使用 Android / iOS 版 Sony Sound Connect，包含下载、传输、升级及中断处理。该说明提示升级后不能回退，且升级过程中充电或关机可能导致耳机无法使用。
- [索尼国际版说明](https://www.sony.com/electronics/support/software/00355433)：同样要求 Sony Sound Connect，不能从说明页推导出供第三方调用的升级 API。
- 项目固定参考提交 `68dfced0403b38114b77f2b374e606ce12a206a8` 的 `ProtocolV2T1.hpp` 中存在 UPDT 消息结构；消息结构不等于完整的固件传输、验证、提交和故障恢复实现。
- 同一参考项目当前 `HeadphonesV2.cpp` 内容 SHA `3b76a3ab07a22f8f369e5555a78faba7845fad00` 未发现可直接复用的升级流程。此结论限于已核对文件，不等于声称所有第三方实现都不存在。
- 另一个公开的 [WF-1000XM5 USB 升级工具](https://github.com/MKobra/WF-1000XM5-firmware-updater) 面向另一型号和 Windows USB/HID 工具链，不作为 WH-1000XM6 蓝牙升级实现依据。

## 实现真正升级前需要补齐

1. 可验证来源的官方 XM6 固件包、机型及地区标识、包完整性与签名验证方式。
2. XM6 的升级握手、传输通道、分包、校验、重试与断点续传流程；需要官方资料或完整的原版 Sound Connect 升级抓包作依据。
3. 写入前条件检查、提交与重启规则、启动后版本回读、失败状态识别及可验证的恢复路径。
4. HarmonyOS 后台传输、屏幕锁定、来电、蓝牙断连和进程回收的处理策略。
